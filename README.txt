TACTICAL STRIKE: COMBAT ZONE
Local browser FPS prototype

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome or Edge.
3. Click "Deploy to Battlefield".
4. Click inside the game to capture the mouse.
5. Controls: WASD move, mouse aim, left click shoot, R reload, Shift sprint, Esc release mouse.

NOTE
This prototype loads Three.js from jsDelivr, so an internet connection is required when loading the game. For a fully offline version, download the matching three.module.js file and update the import path in index.html.
